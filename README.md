# Plasma kinetics 2.8.2

Кинетическая модель смеси H, He, Li и других зарегистрированных элементов в плоском слое. Эволюционируют электронное распределение и отдельные распределения каждого атомного уровня, иона и зарегистрированного молекулярного носителя. Излучение связывает ячейки слоя. Область применимости определяется покрытием данных и приближениями выбранных операторов.

## Быстрый запуск

Распакуйте **всю** папку проекта. `run.py`, `src`, `data` и `configs` должны находиться рядом. Нужен 64-битный CPython 3.11+; проверенная в этой сборке среда указана в [отчёте проверки](docs/VALIDATION_2_8_2_RU.md). Для окон нужен Tkinter.

На Windows откройте `START_WINDOWS.bat`. Для диагностики запуска: `START_WINDOWS.bat debug`. Если используете консоль с уже выбранным Python:

```bash
python -m venv .venv
```

Windows PowerShell, без изменения системной политики активации:

```powershell
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
.\.venv\Scripts\python.exe run.py --gui
```

Linux/macOS:

```bash
.venv/bin/python -m pip install --only-binary=:all: -r requirements.txt
.venv/bin/python run.py --gui
```

## Первый физический тест

В окне запуска выберите **`configs/study_01_decay.json`**. В нём все параметры уже заданы: H 2p, `1e8 см⁻³`, единственный переход 2p→1s, `A=6.27e8 с⁻¹`, `t_end=5/A`. Концентрации и сетки вручную менять не нужно.

```bash
python run.py --config configs/study_01_decay.json --check
python run.py --config configs/study_01_decay.json
```

`--check` создаёт модель, но не интегрирует её. Вторая команда выполняет весь тест. Ожидание: `n_2p(t)=1e8 exp(-A t)`. Через `5/A` остаётся около `6.737947e5 см⁻³`. Это проверка реализации распада с заданным A; сам A независимо сравнивают с атомным источником.

Все 29 конфигураций из задания студенту находятся в `configs/study_*.json`. Их можно пересоздать командой `python tools/make_student_tests.py`. Сценарии T07 с недостаточной ручной сеткой и T08 вне диапазона коэффициента намеренно проверяют ограничения; для них не ожидается обычный успешный расчёт полного механизма.

## Концентрации и логарифмические оси

Откройте **Результаты** после расчёта.

1. Нажмите **Концентрации компонентов** или **Населённости уровней** в постоянной верхней панели.
2. Выберите компоненты/уровни и ячейку. Для пространственного профиля выберите «По расстоянию» и момент времени.
3. Вверху задайте **Масштаб X** и **Масштаб Y**: линейный, логарифмический или симметричный log.
4. Нажмите **Построить выбранное**, затем **Сохранить PNG**.

Галочки на вкладке «Графики» позволяют одновременно выбрать несколько величин. Переключение на вкладку «Реакции» больше не подменяет этот выбор. Кнопка внутри реакционного подраздела явно выбирает реакционный график. `log` показывает положительные значения; нули не заменяются искусственным фоном. Для знаковых величин подходит `symlog`.

## Результаты и код завершения

По умолчанию: `сохранение.csv`, `кинетика_уровней.csv`, `реакции_по_времени.csv`, `топ5_по_времени.csv`, `данные_для_графиков.npz`, `О_результатах.txt`. Полные распределения и исходные ссылки сохраняются в NPZ; все графики строятся из него.

Код `0` — расчёт завершён без зарегистрированных замечаний. Код `2` — результаты сохранены, но есть провал баланса или неполнота физических данных; смотрите `О_результатах.txt` и метаданные. Иной ненулевой код с «Ошибка» — остановка. Наличие результатов само по себе не доказывает физическую применимость.

## Подготовка репозитория

В архив включены исходники, локальные научные таблицы, примеры, тесты и GitHub Actions. Кэши, результаты расчётов, временные файлы и локальные окружения исключены. Распакуйте архив, откройте папку с `run.py` и загрузите её содержимое в свой репозиторий. При загрузке через Git сохраняются и файлы `.github`, `.gitignore`, `.gitattributes`.

Подготовленные атомные таблицы H/He/Li и исходные фото-таблицы поставляются локально. Пример Na предусматривает сетевую подготовку (`offline=false`); один дескриптор нового элемента не равнозначен готовому набору всех его данных.

```bash
git init
git add .
git status
git commit -m "Prepare plasma kinetics 2.8.2"
```

Адрес удалённого репозитория задаёт владелец. Сведения о происхождении и лицензировании исходных данных — в [NOTICE](NOTICE.md). Публикация не выполняется командами сборки или тестами.
