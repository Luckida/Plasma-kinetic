# Plasma kinetics 2.5 — состав газа и пробный спектр

Запуск Windows: **START_WINDOWS.bat**. Основной пример — **configs/gas_probe.json**. Выберите **Состав и спектр**, задайте газ в таблице, сохраните и нажмите **Запустить**.

- Состав задаётся концентрациями, долями с общей концентрацией или долями с давлением заполнения.
- Пробный спектр: ровный свет в заданном диапазоне или TXT/CSV/TSV/DAT/ASC/XLSX. Заголовки колонок произвольные; единицы и колонки выбираются в окне, есть предпросмотр.
- Пробный свет отделён от действующей накачки. По умолчанию газ покоится; дрейф, пучки, внешнее поле, источники частиц, BGK и оценочные сечения выключены.
- В результатах есть график и CSV входного/прошедшего пробного света, поглощения по длине волны, времени и расстоянию, а также исходные распределения, реакции и спектральные линии.

[Иллюстрированная инструкция по новому вводу](docs/INPUTS_2_5_RU.md). В архиве также есть пример обычной смеси H–He–Li: **configs/gas_probe_H_He_Li.json**. Настройки обеих стенок и независимой пространственной инжекции находятся в **Дополнительно: Slab**; поток частиц для задания исходного газа не нужен. Старые демонстрационные конфигурации сохранены и могут содержать специально включённые пучки/накачку.

## Запуск из консоли

Требуется CPython 3.11+ (64 bit) и Tk для интерфейса. Установите зависимости:

```bash
python -m pip install -r requirements.txt
python run.py --gui
```

Расчёт основного примера, построение графиков, тесты:

```bash
python run.py
python run.py plot outputs/output_gas_probe
python run.py test
```

Для основного H–He и H–He–Li примеров поставляются подготовленные данные и локальные фото-таблицы; сеть для этих проверенных запусков не требуется. Новый элемент может потребовать импорта его данных через **Элементы и данные**. Инструкция по расширению: [ADDING_ELEMENTS_RU.md](docs/ADDING_ELEMENTS_RU.md).

## Что проверено

129 тестов, включая настоящие окна Tk с виртуальным X-дисплеем, без пропусков. Выполнены полный H–He, H–He–Li и запуск с долями и русским CSV: расчёты и графики созданы. Балансы заряда, ядер, массы, энергии, фазовой кинетики и реакционных фотонов прошли проверки. Журналы и сводка находятся в **validation/**.

Пассивный пробный свет сейчас рассчитывает связанные линии в приближении слабого зонда; континуальное поглощение и добавка собственного излучения в этот луч не включены. Линии модели основаны на энергиях LS в вакууме. Физическая база конечна: неизвестные каналы перечисляются в **quality.json**, **data_gaps.csv** и отчётах химии. Код 2 означает завершение с такими замечаниями; выходные файлы при этом созданы. Успешные балансы не доказывают полноту базы или сходимость по сеткам. Нативный Windows-запуск в среде сборки не проверялся.
