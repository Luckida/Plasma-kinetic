# Проверки кода и физической применимости

## Программные тесты

```bash
python run.py test
```

Запускаются `tests/tests_*.py` стандартным unittest. В синтетических тестах коэффициенты явно помечены; они не поставляются в `data` как физические сечения. Тесты читают реальные методы операторов, ввода, экспорта и выбора графиков. На Linux без дисплея Tk-классы пропускаются. Для их выполнения нужен обычный дисплей или `xvfb-run -a python run.py test`.

Новые регрессии: `tests_grid_validation.py` проверяет конкретные поля ошибочной сетки и остановку до атомного банка; `tests_plot_selection.py` проверяет, что вкладка реакций не подменяет концентрации, и сверяет данные log-графика с сохранёнными n(t). Эти проверки работают без дисплея. Полные Tk-тесты проверяют также реальные элементы окна.

## Первый реальный тест

```bash
python run.py --config configs/study_01_decay.json --check
python run.py --config configs/study_01_decay.json
python tools/check_first_test.py
```

Первые два запуска используют локальные реальные таблицы H, без сетевого получения данных. Последняя команда независимо сравнивает сохранённую динамику с экспонентой, проверяет единственный разрешённый канал, версии и статусы балансов. Она пишет короткий отчёт `validation/first_test_2_8_2.json`; изображения и большой NPZ остаются в `outputs` и не коммитятся.

## Параметры восьми групп

| Группа | Файлы в configs | Что проверяется |
|---|---|---|
| T01 | `study_01_decay.json` | Излучательный распад H 2p→1s, A и число событий |
| T02 | `study_02_energy.json`, `study_02_reverse.json` | Обмен энергией с EEDF, число электронов, детальный баланс |
| T03 | `study_03_below/above/maxwell.json` | Порог H, выход электронов и зависимость от формы EEDF |
| T04 | `study_04_cold/hot/control.json` | Отсутствие искусственной затравки при n_e=0 |
| T05 | `study_05_base/density/length.json` | Пассивное поглощение He 1083 нм и закон удвоенного столбца |
| T06 | `study_06_dt*.json`, `study_06_e*.json`, `study_06_z*.json` | Сходимость по времени/энергии и аналитический свободный перенос |
| T07 | `study_07_manual50/manual300/auto.json` | Тепловая сетка при 300000 K; manual50 должен быть отвергнут |
| T08 | `study_08_T*.json` | Две ветви He*+H, состав продуктов и область 300…4500 K |

Запись со слешами в таблице — сокращение нескольких имён, а не буквальное имя файла. Полный генератор с каждым числом находится в `tools/make_student_tests.py`; готовые JSON не требуют копирования из Word. Подробное задание ранее выдано в `Physics_model_test_assignment_RU.docx`; исходные параметры этого задания здесь сохранены, с исправленной записью UTF-8 для Windows.

## Что считается физической проверкой

Для каждого сценария сохраняют входы, версию и хеши; строят эталон и результат на одинаковых осях, вычисляют ошибку, проверяют балансы и отдельно изменяют шаг/сетки. Малую ионную прибавку сравнивают по самой прибавке, а не по большой начальной концентрации. Для открытого слоя считают потоки через границы; для молекул — ядра каждого элемента.

Численная экспонента проверяет применение A, а не экспериментальную точность A. Совпадение с `90/T` проверяет интерполяционное замыкание RD82, а не доказывает измеренное σ(E). Необходимы независимые сравнения с публикациями и экспериментом в выбранной области. Общие балансы не доказывают полноты каналов, разрешения профилей или применимости BGK.

Фактически выполненные проверки этой сборки отделены от перечисленного плана в `VALIDATION_2_8_2_RU.md`. GitHub Actions настроен для повторения тестов на Python 3.11/3.12 под Linux и Windows; настройка workflow не означает, что эти удалённые запуски уже состоялись.
