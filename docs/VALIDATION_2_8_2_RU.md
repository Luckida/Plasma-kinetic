## Программные регрессии

`python run.py test`: **187 тестов в отчёте unittest, OK, 6 пропусков**. Пропущены графические Tk-группы/проверки из-за отсутствия дисплея в этой среде. Их код сохранён и включён в CI с Xvfb для Linux и в Windows-задание. Удалённые GitHub Actions и нативный Windows-запуск в этой работе не выполнялись.

Проверены, в частности: указание фактических неверных полей сетки; отсутствие вызова атомной подготовки при неверной сетке; открытие неверного старого JSON для исправления; независимость выбора концентраций от вкладки реакций; одновременный выбор концентраций и скоростей; log-оси и численное соответствие кривой сохранённым концентрациям; чтение поставленного источника без сети; выявление испорченного источника и отсутствующей квитанции.

Новые проверки логики выбора графиков используют реальные методы `ResultBrowser` и численные графики с Tcl-переменными, без отображения окна. Это подтверждает логику и данные, но не подменяет визуальную проверку размеров окна на Windows.

## Документация и состав поставки

Карта функций получена AST-разбором актуальных файлов; `tools/build_reference.py --check` сравнивает генерируемые ссылки с кодом. Реестр химии включает все **60 декларативных записей** пяти групп, включая альтернативы/оценки. Python-синтаксис, JSON и локальные ссылки новых основных документов проверяет `tools/check_repository.py`.

Для чистой поставки исключаются вычислительные кэши, старые журналы, результаты и частичные временные файлы. Исходные фото-таблицы и их квитанции сохранены в `data/radiation/photoionization_sources` с теми же байтами. Правило `data/** -text` в `.gitattributes` предотвращает изменение окончаний строк Git и нарушение научных контрольных сумм.

Из чистого дерева без прежних кэшей успешно выполнен `--check` штатного `configs/gas_probe.json`: подготовлены 57 состояний смеси H–He, выбран активный базис из 12 состояний. Это проверка загрузки и начального состояния; она не объявляется новым полным временным расчётом этого примера.
