# Plasma kinetics 2.6 — выбранные результаты и понятные источники

**Windows: запустите START_WINDOWS.bat.** Состав и накачки задаются кнопкой **Состав и спектр**, нужные картинки — кнопкой **Результаты**.

## Короткий порядок работы

1. Выберите `configs/gas_probe.json` для H–He, `gas_probe_H_He_Li.json` для H–He–Li или `pulsed_sources.json` для примера с тремя накачками.
2. В **Состав и спектр** задайте газ. В **Источники в слое** добавьте нужные источники электронов, ионов или света, их координаты и время действия. Свет на входе слоя можно также задать на отдельной вкладке **Свет на границе**.
3. Сохраните параметры и нажмите **Запустить**.
4. Откройте **Результаты**, отметьте нужные графики, выберите компоненты, уровни или реакции. Нажмите **Построить выбранное**.
5. Во вкладке **Масштабы** доступны независимые линейные/log/symlog оси, размер текста и диапазоны. **Сохранить PNG** записывает только построенные изображения.

[Иллюстрированная инструкция 2.6](docs/RESULTS_AND_SOURCES_2_6_RU.md).

## Теперь в папке расчёта только нужные данные

| Файл | Содержание |
|---|---|
| `сохранение.csv` | Масса, заряд, максимальная невязка кинетики всех уровней и электронов; дополнительно энергия |
| `кинетика_уровней.csv` | Все компоненты, атомные уровни, ионы, молекулярные реагенты и электроны по времени и расстоянию |
| `реакции_по_времени.csv` | Все включённые реакции: реагенты, продукты, скорости и интегралы событий |
| `топ5_по_времени.csv` | Общие лидеры и top-5 заселения/расселения каждого уровня, компонента и электронов |
| `данные_для_графиков.npz` | Один служебный файл для окна графиков; вручную открывать не требуется |
| `О_результатах.txt` | Краткое описание, результат проверок, параметры источников и ограничения физических данных |

Отдельные файлы для каждой ячейки, столкновения, распределения и технической проверки в обычном режиме не создаются. Ранее созданные диагностические файлы с известными программными именами удаляются после успешного сохранения нового результата. Пользовательские заметки и выбранные PNG сохраняются.

## Ввод накачек

Для частиц задаются **концентрация пучка, см⁻³**, **скорость u_z, см/с**, температура распределения, координата и интервал импульса. Концентрация пучка вместе со скоростью определяет ввод через плоскость: `n × |u_z|`. Начальный состав газа задаётся отдельно в таблице. Скорость и энергия дискретного источника согласуются с заданными значениями; при недостаточной фазовой сетке выдаётся пояснение.

Для света используется форма из пробного спектра или отдельный TXT/CSV/XLSX. Форма нормируется по интегралу до 1, а **множитель в Вт/см²** задаёт полную мощность через плоскость. В окне показываются диапазон и средняя энергия фотонов, мощность, фотонный поток и энергия импульса. Поддержаны nm/A/um/eV/Hz и прежние текстовые форматы.

## Проверка сборки

155 тестов пройдены, включая настоящие окна Tk, выбор графиков, сохранение PNG, top-5, локальные балансы электронов, заданные скорости пучков и мощность света. Полностью выполнены H–He, H–He–Li и три независимые накачки. Журналы — в `validation/`. Нативный Windows-запуск в среде сборки не выполнялся.

База физических данных конечна. Ограничения приводятся в `О_результатах.txt`; код 2 означает завершённый расчёт с замечаниями к данным. Масса проверяется в принятом моделью приближении одинаковых ядерных масс стадий. Балансы не доказывают полноту реакций и сходимость по сеткам. Пробный свет даёт связанные линии в приближении слабого зонда; континуум и добавка собственного излучения в пробный луч не включены. Линии LS приводятся в вакууме.

Консоль:

```bash
python -m pip install -r requirements.txt
python run.py --gui
python run.py --config configs/pulsed_sources.json
python run.py plot outputs/output_pulsed_sources --metrics levels,top5 --log-y
python run.py test
```

Источники физических данных и инструкции по расширению сохранены в `docs/LITERATURE_RU.md`, `MODEL_RU.md` и `ADDING_ELEMENTS_RU.md`. Подготовленные атомные/фото-таблицы для примеров включены. Выходные папки прежних запусков в дистрибутив не включены.
