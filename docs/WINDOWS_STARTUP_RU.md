# Запуск в Windows — исправление 2.1.1

Основной файл запуска — **START_WINDOWS.bat**. Распакуйте весь архив в отдельную папку и откройте этот файл двойным щелчком.

Сообщение «Unable to create process … anaconda3\pythonw.exe … Не удаётся найти указанный файл» возникает до выполнения Python-кода программы. Windows Launcher пытается использовать путь к отсутствующему интерпретатору. Поэтому обработчик ошибок внутри START_GUI.pyw не успевает сработать.

Новый запуск выполняет найденный `python.exe` напрямую. Проверяются CPython 3.11+, 64 бита, импорт Tkinter и работоспособность Tcl. Старые/нерабочие пути пропускаются. Если подходящий Python не найден, открывается выбор `python.exe`; при отсутствии установленного Python потребуется установить 64-битный Python с Tkinter с python.org.

Источники поиска: явно заданный `PLASMA_PYTHON`, ранее сохранённый путь, окружение проекта/активное окружение, стандартные папки установки, записи установленного Python по PEP 514, PATH и список Python Launcher. Чтение списка Launcher не запускает его интерпретатор по умолчанию. Найденный путь сохраняется в `python_path.txt` рядом с программой. Можно заменить его одной строкой с полным путём к нужному `python.exe`; путь к `pythonw.exe` преобразуется в соседний `python.exe` и проверяется.

Обычный запуск открывает окно без постоянной консоли. В PowerShell используется только процессная настройка выполнения локального скрипта; системные привязки файлов и настройки реестра не изменяются. Программа получает собственное окружение без унаследованных PYTHONHOME/PYTHONPATH, которые могут указывать на другую установку.

Если окно не открылось:

1. Откройте `startup.log` в папке программы. В нём находятся проверенные пути и текст ошибки запуска.
2. Для вывода в консоль откройте терминал в этой папке и выполните:

```bat
START_WINDOWS.bat debug
```

3. После появления основного окна журнал подготовки данных и расчёта находится в `launcher.log`. Это следующий этап, отдельный от поиска Python.

При известном рабочем интерпретаторе можно запустить окно явно из терминала в папке проекта:

```bat
"C:\путь к установленному Python\python.exe" run.py --gui
```

Первое получение библиотек/атомных данных требует интернета. Этот патч меняет способ запуска; физические коэффициенты и численный решатель сохранены.

Основания реализации: [Python 3.11 — Windows Launcher и привязки](https://docs.python.org/3.11/using/windows.html), [PEP 514 — обнаружение установок](https://peps.python.org/pep-0514/), [параметры Windows PowerShell](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_powershell_exe?view=powershell-5.1).
