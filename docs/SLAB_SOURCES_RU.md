# Slab: две стенки и пространственные источники

## Запуск из окна

1. Запустите `START_WINDOWS.bat`.
2. Выберите `configs/slab_H_He_Li_sources.json`.
3. Откройте **Slab: источники и стенки**.
4. На первой вкладке задайте длину, число ячеек, конец расчёта и свойства обеих стенок.
5. На второй вкладке выберите режим `ions`, `electrons` или `radiation`. Введите координату, начало/конец воздействия и параметры. Нажмите **Добавить новый**. Для изменения выбранной строки — **Применить к выбранному**.
6. Нажмите **Сохранить параметры**, закройте редактор и запустите расчёт.

Источники независимы, их можно включать одновременно. Добавление ионов не добавляет автоматически электроны. В источнике `particles` можно указать нейтральный атом, конкретный уровень или молекулярный носитель.

Реальный Windows-сеанс в среде подготовки не проверялся. Численное ядро, форматы конфигурации и обработчики валидации проверяются тестами; окно использует стандартный tkinter.

## Единицы и сетка

* x отсчитывается от начала слоя; `0 <= position_cm <= thickness_cm`.
* Сетка конечных объёмов: Δx=L/N, центр ячейки x=(i+1/2)Δx.
* `rate_cm2_s` — полный поток источника на единицу поперечной площади, **см⁻² с⁻¹**. Точечный источник даёт объёмный член rate/Δx в содержащей его ячейке. Поэтому изменение N не изменяет число вводимых частиц.
* `width_cm>0` распределяет поток по пересечениям ячеек с источником конечной ширины. Источник должен целиком находиться в слое.
* Точки начала/конца импульсов включаются в сетку времени, даже если их нет среди обычных отсчётов. Интервал активности [start_s,stop_s).

Уточняйте Δx и шаг времени: точка ввода частиц разрешается ячейкой, не подъячеечным распределением. Результаты в одной ячейке не являются пространственным профилем. Для фотонного листа координата внутри ячейки учитывается в длине пути точно для кусочно-постоянной непрозрачности.

## Пример трёх источников

```json
"spatial_sources": [
  {
    "id": "protons", "mode": "ions", "species": "H+",
    "position_cm": 0.15, "width_cm": 0,
    "start_s": 0, "stop_s": 5e-9,
    "rate_cm2_s": 1e17,
    "distribution": {"Ti_K": 650, "uz_cm_s": 3e6}
  },
  {
    "id": "electrons", "mode": "electrons",
    "position_cm": 0.35, "width_cm": 0,
    "start_s": 1e-9, "stop_s": 7e-9,
    "rate_cm2_s": 1e17,
    "distribution": {"Te_eV": 1.5, "angular_bias": 0.5}
  },
  {
    "id": "light", "mode": "radiation", "position_cm": 0.7,
    "start_s": 0, "stop_s": 8e-9,
    "spectrum_file": "../data/radiation/point_spectrum.csv",
    "scale": 0.1, "direction": "both", "mu": 1
  }
]
```

Пути в JSON отсчитываются от папки конфигурации. Для электронного пучка через JSON доступны `uz_cm_s`, список `beams` с Te и долями, либо `distribution_file`. Для тяжёлых частиц — Ti, дрейф, несколько пучков либо фазовый CSV. Это те же распределения, что используются для начальных условий.

`energy_max_eV=auto` для электронов учитывает параметры источников и энергии накачки. Сетка тяжёлых частиц остаётся явно задаваемой: она должна покрывать дрейф, тепловые хвосты и продукты экзотермических реакций. Выход за существенную часть верхней границы останавливает расчёт; скрытого обрезания энергичных продуктов нет.

## Внутренний свет

CSV имеет столбцы `wavelength_A;four_pi_J_lambda_erg_cm2_s_A`, как прежняя внешняя накачка. Величина представляет спектральный скалярный интеграл направленного пучка. Нормальный поток мощности равен |μ|·4πJ. `direction` принимает `left`, `right`, `both`. При `both` заданный спектр делится поровну между двумя направлениями, а не удваивается.

Источник представляет плоский лист в геометрии 1D, без потерь на поперечную расходимость. Учитываются поглощение, переизлучение и включённое электронное рассеяние в общем уравнении переноса. Для внутреннего фотонного источника `width_cm=0`. Внешняя граничная накачка из `radiation` может работать одновременно; для её выключения задайте `radiation.scale=0`.

## Стенки x=0,L

```json
"particle_boundary": {
  "kind": "walls",
  "walls": {
    "left": {
      "quenching_probability": 1,
      "neutralization_probability": 1,
      "sticking_probability": 0,
      "electron_absorption_probability": 0.5
    },
    "right": {
      "quenching_probability": 0.7,
      "neutralization_probability": 1,
      "sticking_probability": 0.1,
      "electron_absorption_probability": 1
    }
  }
}
```

Стенка получает поток только от летящих к ней частиц. У атомов указанная доля возбуждённых возвращается в основном состоянии; у атомных положительных ионов указанная доля возвращается нейтральными. Остальные отражаются с прежним внутренним состоянием. `sticking_probability` сначала удаляет указанную долю тяжёлого потока. Электроны поглощаются или зеркально отражаются. Тепловое переиспускание и вторичная эмиссия не предполагаются.

Вероятности не являются универсальными значениями для стекла/металла. Значения 1 и 0 в примере задают идеализированный эксперимент. При необходимости используйте отдельные значения для вида через `overrides`, например `"overrides":{"HeI_2_3S":{"quenching_probability":0.3}}`. Для молекулярных ионов автоматическая диссоциативная нейтрализация отсутствует.

Энергия внутреннего тушения и разность входящего/возвращённого кинетического потока учитываются как энергия стенки. Изменение заряда учитывается как ток в поверхностный резервуар; искусственного восстановления квазинейтральности нет. Для постоянного независимого ввода зарядов нужно осознанно выбирать предписанное поле или приближение Пуассона; самосогласованная эволюция заряда изолированной стенки не реализована.

## Что смотреть в результатах

| Файл | Содержание |
|---|---|
| `spatial_profiles.csv` | Время, x, все уровни/ионы/молекулярные носители, концентрации, температуры моментов и дрейфы |
| `spatial_kinetics.csv` | Локальные скорости и интегралы всех ненулевых реакций, полные формулы и источники |
| `strongest_lines_by_position.csv` | Сильнейшие линии отдельно для каждой ячейки и времени; число линий задаёт `diagnostics.spatial_top_lines` |
| `lines_by_position.csv` | Все линии, локальная эмиссия, непрозрачность, эквивалентная ширина отдельной ячейки и два ранга |
| `spectra_by_position_final.csv` | Полный локальный спектр в конце: непрозрачность, эмиссия, 4πJ, τ ячейки и τ к границам |
| `spatial_radiation_history.npz` | Те же спектральные величины во все сохранённые моменты времени |
| `wall_history.csv` | Налетевшие, потушенные, нейтрализованные, прилипшие и возвращённые колонки на каждой стенке; энергия и заряд |
| `spatial_source_history.csv` | Время работы и суммарное число введённых частиц каждого источника |
| `reaction_top5.csv` | Источники/стоки выбранного уровня; суммарный вклад и доля каждой ведущей реакции |
| `conservation.csv`, `quality.json` | Балансы и известные ограничения |

В столбцах моментов прежнее имя `ne_cm3` означает число частиц данного вида, в том числе для тяжёлых частиц. Длины волн основаны на импортированных LS-энергиях ADAS; это не таблица NIST для точной идентификации. Например, модельная группа Li I 2p–2s здесь около 673.4 нм, поэтому перед сравнением с лабораторной резонансной группой около 671 нм нужны экспериментальные энергии. Столбцы `wavelength_basis` и `atomic_data_source` обозначают это явно.

Локальное излучение — объёмная мощность, а локальная эквивалентная ширина относится к Δx. Эти величины не равны наблюдаемому спектру всего слоя с перекрытием линий. Выходящие с двух сторон спектры всего слоя находятся в `spectrum_final.csv`.

После расчёта окно строит `spatial_profiles.png`, `spatial_lines.png`, `spatial_chemistry.png`. Полные фазовые распределения всегда есть в `mixture_history.npz`. Флаг `diagnostics.phase_history_csv=false` отключает громоздкое дублирование этих массивов в CSV.
