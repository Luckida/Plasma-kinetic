# Ошибки запуска и графиков

## Присланный launcher(1).log

В журнале запущен `gas_probe.json`; остановка произошла на этапе «Энергетические сетки и распределения частиц», до интегрирования:

```text
phase_grid: 0<Emin<Emax, energy_points>=16, angular_points>=4
```

Это сообщение старого `PhaseGrid.__init__` означает нарушение хотя бы одного из четырёх структурных условий. Оно не печатало реальные значения, поэтому по этому журналу нельзя достоверно назвать неверное поле. Название `phase_grid` использовалось также при создании тяжёлой сетки, что дополнительно запутывало диагностику. Это не сообщение о неизвестной химической реакции и не доказательство недостаточной физической теории.

В 2.8.2 единая проверка выполняется до атомной подготовки и при сохранении редактора. Она различает электронный и тяжёлый блоки, показывает **все фактические параметры** и нарушенные условия. Оба числа угловых узлов теперь видны в интерфейсе. Дробные числа узлов, bool, NaN, бесконечность и неправильные границы не проходят проверку. Автоматической подмены пользовательского ввода нет.

## Как выполнить первый тест

1. Распакуйте новую сборку целиком в отдельную папку; не копируйте только один `.py` поверх другой версии.
2. Запустите `START_WINDOWS.bat`, выберите **configs/study_01_decay.json**. Это готовый первый тест, а не произвольный `gas_probe.json`.
3. Нажмите «Запустить». Для консоли используйте команды ниже из папки с `run.py`.

```bash
python run.py --config configs/study_01_decay.json --check
python run.py --config configs/study_01_decay.json
python tools/check_first_test.py
```

В нём electron Emin/Emax=`1e-4/200 эВ`, 128 энергий и 8 углов; heavy Emin/Emax=`1e-6/50 эВ`, 64 энергии и 8 углов; T газа=300 K; одна периодическая ячейка. Все параметры уже сохранены. Результаты находятся в `outputs/study_01_decay`. Проверка кривой использует `A=6.27e8 с⁻¹` и закон экспоненты.

## Как исправлять свои параметры

В «Параметры → EEDF / ионы → Сетки кинетической энергии» установите для обеих сеток положительный Emin, Emax=`auto` либо число больше Emin, не менее 16 энергетических и 4 угловых узлов. Для обычного контрольного расчёта можно начать со 128/8 для электронов и 64/8 для тяжёлых частиц. Это начальное разрешение, а не универсальная гарантия сходимости.

При T=300000 K граница тяжёлой энергии 50 эВ недостаточна: `8kT≈206.816 эВ`. Выберите heavy Emax=`auto`; при нулевой средней скорости и этих тепловых входах получается около 227.497598 эВ. Не уменьшайте физическую температуру ради запуска. Подробности старого случая сохранены в `STARTUP_GRID_2_8_1_RU.md`.

Если расчёт позже выдаёт «Продукты ... вышли за Emax», требуется расширить диапазон продуктов и повторить проверку сходимости. Автоматическая граница не является гарантией покрытия произвольной дальнейшей эволюции.

## Концентрации и масштабы

Раньше `ResultBrowser.options` при открытой вкладке «Реакции» принудительно подменял набор отмеченных величин реакционным графиком. Поэтому даже выбранные концентрации могли не попасть в построение. Настройки `log` и `symlog` существовали, но были спрятаны на отдельной вкладке.

В новой версии вверху окна постоянно находятся кнопки **Концентрации компонентов**, **Населённости уровней**, **Скорости реакций**, а также обе шкалы осей. После быстрого выбора уточните строки и нажмите «Построить выбранное». Просмотр реакционного справочника больше не меняет галочки. Кнопка «Построить» внутри реакционного подраздела явно выбирает его текущий режим.

При log нулевые/отрицательные точки не рисуются. Они остаются в исходных данных и не заменяются маленькими положительными числами. Симметричный log допускает знак и ноль. Логарифм по времени исключает t=0; начальное значение доступно в таблице или на линейной оси.

## Другие остановки

| Сообщение/симптом | Действие |
|---|---|
| `ModuleNotFoundError` | Установить `requirements.txt` тем же интерпретатором, которым запускается `run.py` |
| `Unable to create process ... python.exe` | Удалить только старое локальное `.venv` или переименовать его и пересоздать доступным Python; научные данные не переустанавливать |
| Ошибка Tk/Tcl | Для Windows нужен Python с Tcl/Tk; запустить `START_WINDOWS.bat debug` и читать полный журнал |
| Относительный путь не найден | Пути в JSON считаются от папки JSON. Держать тесты в `configs` или согласовать пути |
| Неверный спектр | Сначала предпросмотр; проверить координату/единицу, столбцы, отрицательный фон и выбранную абсолютную мощность |
| `Шаг ниже min_step_s` | Изучить причину фазового стока/жёсткости и сходимость; увеличение max_steps само по себе её не устраняет |
| Результаты сохранены, код 2 | Открыть `О_результатах.txt`: неполнота данных и провал баланса различаются. Не скрывать предупреждение ради кода 0 |
| Нулевые электроны при высокой Te | Задать n_e, ионы или реальный источник. Температура без частиц их не создаёт |
| k(T) вне области | Выбрать применимые данные/условия; произвольная экстраполяция или отключение контроля не делает модель достоверной |

Проверенные входы предотвращают описанную ошибку сетки. Для новых физических условий нужны также подходящие данные и численная сходимость; обещание отсутствия любых ошибок для произвольного JSON было бы неверным.
