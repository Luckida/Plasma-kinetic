# Plasma kinetics 2.4 — He–H–Li и пространственные источники

Запуск Windows: **START_WINDOWS.bat**. Новый пример: **configs/slab_H_He_Li_sources.json**. Кнопка окна **Slab: источники и стенки** задаёт обе стенки и независимые источники ионов, электронов и света.

**Научная полнота ограничена:** 22 ион–атомных канала He–Li добавлены по первичным данным; He*–Li Пеннинг и распределение продуктов He*–H⁺ содержат явно обозначенные приближения. Радиационные каналы He*–Li⁺, часть сечений Li и молекулярная LiH/HeLi⁺-кинетика остаются неполными. Это подробно, с влиянием на применимость, изложено в аудите. Версия не объявляет их рассчитанными по умолчанию.

* `docs/PROCESS_AUDIT_2_4_RU.md` — что было, что добавлено и чего не хватает.
* `docs/SLAB_SOURCES_RU.md` — окно, единицы, источники, стенки, пространственные спектры.
* `docs/ADDING_ELEMENTS_RU.md` — унифицированное добавление элемента и его реакций.
* `docs/LITERATURE_RU.md` — первичные ссылки, базы, точное назначение каждого источника.
* `validation/` — автоматические проверки и сравнение извлечённых сечений с опубликованными k(T).

Пример включает полный имеющийся атомный базис (`mode=all`), чтобы избежать повторных запусков при его расширении. Это конечный банк данных, а не все физические уровни атома. Расчёт может занимать минуты; уменьшение шага и увеличение сеток требуется для оценки точности. Основные данные H/He/Li подготовлены; сохранены их происхождение и контрольные суммы. Для других пресетов, например Na, возможна подготовка из сети.

Ниже сохранена инструкция прежней версии; новые настройки описаны в перечисленных документах.

# Plasma kinetics 2.1.1

Версия построена **из приложенного `helium_point_v1_8.zip`**. Это расчёт смеси с общей функцией распределения электронов, отдельными распределениями тяжёлых состояний и общим излучением. Добавлен оператор межкомпонентной химии: реакции действительно меняют населённости, зарядовые состояния, EEDF и распределения продуктов.

## Запуск

1. Распакуйте архив в отдельную папку. Нужен 64-битный Python 3.11+.
2. В Windows откройте **`START_WINDOWS.bat`**. Запуск найдёт рабочий Python, проверит 64 бита, версию 3.11+ и Tkinter. При необходимости предложит выбрать `python.exe`. Выберите `configs/mixture_H_He.json` и нажмите **«Запустить»**. Окно устанавливает зависимости и готовит данные при необходимости.
3. Отдельная кнопка **«Элементы и данные»** открывает подготовку атомных таблиц, импорт сети UMIST, добавление нового элемента, импорт сечений LXCat и проверку смеси.

Если при открытии `.pyw` появляется сообщение об отсутствующем `anaconda3\pythonw.exe`, используйте `START_WINDOWS.bat`: оно не зависит от этой привязки. Диагностика запуска сохраняется в `startup.log`; подробности — [запуск в Windows](docs/WINDOWS_STARTUP_RU.md).

Первое получение атомных данных требует интернета. Повторные запуски используют проверенные таблицы. Скачанные таблицы OPEN-ADAS/CCC и индивидуальные кэши в дистрибутив не вложены: их получает импортёр. Физические коэффициенты включённых химических реакций находятся в `data/reactions/`.

Через консоль из папки проекта:

```bash
python -m pip install -r requirements.txt
python run.py --config configs/mixture_H_He.json
python run.py plot outputs/output_mixture_H_He
python run.py test
```

Для короткой проверки именно нового химического оператора выберите `mixture_H_He_chemistry.json`: в этом контрольном примере атомные электронные/фотонные процессы явно выключены. Для совместного расчёта используйте `mixture_H_He.json` или `mixture_H_He_Li.json`.

## Что изменено

- Два канала He(2³S)+H: Пеннинговская и ассоциативная ионизация, с отдельным HeH⁺.
- He(2³S)+He(2³S): отдельные каналы He⁺ и He₂⁺; включены два канала диссоциативной рекомбинации He₂⁺.
- Согласованная H/He-химия с H⁻, H₂, H₂⁺, H₃⁺ и HeH⁺: перенос заряда, ионные реакции и взаимная нейтрализация. Молекулы здесь представлены эффективными основными состояниями.
- Резонансная H⁺–H перезарядка с реальной σ(E) и передачей распределений скоростей. Её нельзя диагностировать только по изменению числа H/H⁺: оно равно нулю.
- Подключён Na I: реальные уровни/A из OPEN-ADAS и доступные электронные σ(E) из CCC. Данные каждого элемента и каждой группы химических реакций отделены.
- Универсальный вход через проверяемые дескрипторы и канонические CSV; импорт сети UMIST и распространённого текстового экспорта LXCat/BOLSIG.

**Это расширенная, но не полная база всей опубликованной физики.** Наличие имени элемента не означает наличия всех его сечений. В частности, каналы He*–Li/Na не подставляются без выбранных абсолютных данных; возбуждённые ионы Li/Na и молекулярные v,J-состояния покрыты неполно. Пробелы и пределы коэффициентов выводятся явно. Зелёные балансы не подтверждают полноту базы.

## Где что находится

| Папка / файл | Назначение |
|---|---|
| `START_WINDOWS.bat`, `START_WINDOWS.ps1` | Запуск в Windows с поиском и проверкой Python |
| `run.py`, `START_GUI.pyw` | Консольный запуск и прямой запуск окна через выбранный интерпретатор |
| `configs/` | Шесть примеров начальных условий |
| `src/` | Текущий решатель, физические операторы, импорт и окно |
| `data/elements/<элемент>/atom.json` | Источники, массы и общая шкала ионных стадий одного элемента |
| `data/elements/<элемент>/<стадия>_n9/` | Подготовленные уровни, A, электронные σ(E) и Υ(T), отдельными CSV; создаются импортёром |
| `data/components/` | Состав и энергии эффективных молекулярных/отрицательных компонентов |
| `data/reactions/<группа>/` | `reactions.json` — стехиометрия; `cross_sections.csv` — σ(E); `rate_coefficients.csv` — k(T); `unsupported.csv` — известные исключения |
| `data/radiation/` | Пробный спектр, слабые переходы, двухфотонные формы и их происхождение |
| `templates/` | Явное соответствие уровней/единиц при импорте LXCat |
| `tests/`, `validation/` | Численные проверки и краткие результаты проверок этой версии |

Предыдущие самостоятельные point/sphere/legacy-решатели, старые дублирующиеся руководства и массивы прежних результатов из рабочего дистрибутива убраны. Исходный приложенный архив не нужен для запуска новой версии.
