# Plasma kinetics · 2.8.1

Расчёт смеси атомов, ионов и зарегистрированных молекулярных носителей с общими электронами и излучением. Сохранены пространственные источники, Slab, стенки и компактные результаты.


## Исправление запуска 2.8.1

У тяжёлых частиц теперь есть Emax=auto. Добавлены точное пояснение недостаточной границы и устойчивая оценка оставшегося времени. [Причина ошибки и проверка ваших параметров](STARTUP_GRID_2_8_1_RU.md).

В список окна запуска добавлен ваш исправленный набор **configs/gas_probe_user_fixed.json**: изменена только энергетическая граница 50 эВ → auto. Температуры и концентрации сохранены. Обычные примеры также доступны в списке. При полностью нейтральном исходном составе автоматическая начальная концентрация электронов равна нулю; температура EEDF сама не добавляет электроны.

## Исправления 2.8

- Списки показывают все уровни сохранённой сети, включая нулевые населённости. Реагенты и ввод частиц предлагаются из банка данных.
- У каждой кривой есть легенда; её место рассчитывается по реальному тексту и входит в PNG. Реакции различаются также по ID.
- «Реакции» описывает все выбранные каналы. «Справочник всех реакций» показывает зарегистрированные каналы, альтернативы, источники, доступные коэффициенты и их ограничения.
- Новая вкладка **EEDF / ионы**: максвелловское начальное распределение по умолчанию, ввод P(E)/EEPF или фазового CSV. Отдельные настройки для компонентов и уровней, свои распределения у источников.
- Согласованы начальные моменты максвелловских распределений; в новых пресетах заданные 300 K воспроизводятся на расчётной сетке.

## Запуск

Для Windows используйте сохранённые BAT-файлы запуска. Нужны 64-битный CPython с Tk и зависимости из requirements.txt.

```bash
python -m pip install -r requirements.txt
python run.py --gui
```

В **Параметрах** задайте состав, EEDF/IEDF, пробный свет и необходимые источники. Сохраните и запустите расчёт. В **Результатах** выберите графики, уровни и реакции; настройте log/symlog или линейные оси на вкладке **Масштабы**. Кнопка **Сохранить PNG** записывает только выбранные изображения. Времена начала накачек отмечаются на временных графиках.

Для частиц источника задаются концентрация [см⁻³] и подписанная скорость [см/с]; инжекция через плоскость равна n·|u_z|. Свет задаётся нормированной формой пробного спектра и множителем мощности [Вт/см²]. Энергетика света выводится в редакторе. Начальный состав и источники задаются отдельно.

## Результаты

По умолчанию создаются шесть файлов:

| Файл | Данные |
|---|---|
| сохранение.csv | Балансы массы, заряда, кинетики уровней и электронов, энергии |
| кинетика_уровней.csv | Все компоненты, реагенты и состояния по времени и ячейкам |
| реакции_по_времени.csv | Реагенты, продукты, скорости и интегралы всех каналов сети |
| топ5_по_времени.csv | Лидеры и top-5 заселения/расселения каждого состояния и компонента |
| данные_для_графиков.npz | Общие массивы и метаданные для интерфейса; вручную открывать не нужно |
| О_результатах.txt | Состояние проверок, параметры источников и ограничения данных |

Старые результаты 2.6–2.7 открываются без пересчёта. Новые сведения о коэффициентах, не включённых альтернативах и согласованные начальные распределения требуют нового расчёта.

## Проверка и границы модели

Пройдены **205 тестов**, включая окна Tk, видимость всех состояний, ввод и сохранение распределений, свёртку по EEDF и полные легенды. Выполнен реальный H–He расчёт: балансы массы, заряда, энергии и кинетики пройдены. В нём 57 состояний, 1276 расчётных каналов и 1285 записей справочника. Журналы — в validation/. Нативный Windows-запуск отдельно не проверялся.

Банк данных конечен. Прошедшие балансы не доказывают полноту физических каналов или сходимость сеток. Коэффициенты сохраняют опубликованные интервалы и оценочный статус; отсутствующие сечения не выдумываются. Код возврата 2 при сохранённых результатах означает замечания к полноте данных или балансам; подробности находятся в результате. Слабый пробный свет рассчитывает связанные линии; кинетика использует скалярные LS-состояния. Максвелловское распределение является начальным условием, которое далее изменяется кинетикой.
